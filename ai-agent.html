COMPASS — AI Agent Architecture

AIが自律して、
業務を実行する。

単一のAIではなく、役割を分けた5つの専門エージェントが協調動作する。人間の介入は「判断が必要な例外」のみ。担当者は交渉・戦略・関係構築に集中できる。

Agents

5つのエージェント、それぞれの役割

各エージェントは専門領域に特化して動作し、処理が完了するとバトンを次のエージェントに渡す。全体をMonitor Agentが監視する。

Agent 01
Intake Agent
データ収集・構造化

あらゆる形式の入力データを受け取り、統一スキーマに変換する。調達業務の「入口」を守るエージェント。

  • PDF・Excel・画像からの見積情報抽出（OCR + LLM解析）
  • メール本文から品目・数量・単価・納期を自動パース
  • EDI・CSVの自動取込・正規化
起動条件：メール受信 / ファイルアップロード / API呼び出し / スケジュール実行
Agent 02
Comparison Agent
見積比較・推奨

複数サプライヤーの見積もりを、過去発注データ・サプライヤースコア・市場価格と照合し、最適選択肢を提示する。

  • 多軸評価（価格・納期・品質・信頼性）の自動スコアリング
  • 過去実績との価格乖離率算出・割高案件フラグ
  • 推奨根拠を日本語で説明
起動条件：Intake Agentが構造化完了 → 自動起動
Agent 03
Matching Agent
三点照合・差異検出

発注書・納品書・請求書の三点照合を24時間自動実行。差異を種別・金額・優先度で分類し、適切な担当者にエスカレーションする。

  • 品目・数量・単価・合計の自動突合
  • 差異分類（金額差 / 数量差 / 品目不一致 / 税計算誤り）
  • 許容誤差範囲の設定と自動承認
起動条件：請求書受領 / 納品データ更新 / 毎日定時バッチ
Agent 04
Approval Agent
承認フロー制御

金額・リスク・緊急度に基づいて承認ルートを動的に決定。不在時の代理設定・タイムアウト処理も自動。

  • 金額閾値・カテゴリ別の承認者マッピングを動的適用
  • Slack / メールへのワンタップ承認通知
  • 承認タイムアウト時の自動リマインド・代理エスカレーション
起動条件：Comparison Agent推奨確定 / 担当者の発注起案
Agent 05
Monitor Agent
全体監視・品質管理

他の全エージェントの稼働状況・処理精度・例外率をリアルタイム監視。システム全体の健全性を保つ。

  • 各エージェントの処理ステータス・エラー率をダッシュボードで可視化
  • 精度低下や処理遅延を検知し自動アラート
  • 週次・月次のパフォーマンスレポート自動生成
起動条件：常時稼働（全エージェントアクティビティを監視）

Design Principles

Human-in-the-Loop 設計の3原則

「AIがすべてを決める」ではない。人間の判断が真に必要な場面でのみ、適切な粒度で介入を求める。

Principle 01
例外のみをエスカレーション

ルール内の案件（約90%以上）はAIが自律実行。担当者への通知は「判断が必要な例外」に限定。

例：金額が月次予算の15%超 → 上長承認をリクエスト。以下は自動実行。
Principle 02
根拠を完全に透明化する

AIが推奨・判断する際は、その根拠を常に確認できる形で提示する。「なぜそのサプライヤーか」が常に分かる。

例：「過去12ヶ月の納期遵守率96%、かつ今回単価が過去平均より−5%」
Principle 03
フィードバックで精度を上げる

担当者が推奨を覆した場合、その理由をAIが学習し次回の推奨精度に反映する。使うほど賢くなる。

例：「このサプライヤーは取引見直し中」→ 以降のスコアリングに自動反映

AIエージェントが実際に動く様子を、貴社データで確認する。
